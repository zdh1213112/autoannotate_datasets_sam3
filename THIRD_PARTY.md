# Third-party components

This repository integrates the following projects:

- [Ultralytics](https://github.com/ultralytics/ultralytics): SAM3 and SAM inference API.
- [SAM 3](https://github.com/facebookresearch/sam3): text-prompted segmentation model.
- [MobileSAM](https://github.com/ChaoningZhang/MobileSAM): segmentation checkpoint.
- PyTorch, OpenCV, PyQt5, NumPy and Pillow.
