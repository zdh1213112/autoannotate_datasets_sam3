灰手套简洁版

启动：python run_gray_gloves_easy.py
使用原来的 Python 环境和模型，不需要安装网页服务。
原 run_gray_gloves.py 和原界面保持不变；新版复用现有检测与导出引擎。

打开项目 / 数据集（Alt+P）：
- 原复核项目：选择含 project.json、review.jsonl 的结果目录。
- YOLO 数据集：直接选包含 images/、labels/ 的目录，也可选 images 或 labels。
  支持 images/train + labels/train，以及 train/images + train/labels 等分目录。
  支持 YOLO-HBB（5 列）和 YOLO-OBB（9 列）；类别读取 classes.txt 或 dataset.yaml/data.yaml。
  本灰手套版本只支持 left/right 两类；缺少类别文件时按 0=left、1=right 读取。
  数据集内类别编号顺序可以不同，保存时会映射回原编号。

直接编辑数据集：
- 查看时不修改标签，也不需要重新运行 SAM3。
- 调框、增删框、改类别后，自动写回原 labels 中对应的 txt，保持该文件原有框格式。
- 首次修改会备份原标签到 数据集/.gray_glove_editor/backups/labels/（分目录亦保留）。
- Ctrl+Z 同时恢复界面和标签文件；重新打开保留已确认状态，重启不保留撤销栈。
- YOLO 标签不包含置信度，列表以“—”显示。框号与左右快捷键无关。
- 遇到损坏或无法解析的标签，会显示错误原因并禁止覆盖该张标签。
- 自动检测 / 视频抽帧在数据集模式下停用；打开原复核项目后恢复。
- 导出按钮用于另存副本：Ctrl+E 导出已确认数据并划分 train/val；
  Ctrl+Shift+E 导出全部当前标注。界面底部格式选项仅用于导出副本。
输入 / 设置：图片目录、视频和 MCAP 抽帧、SAM3 参数都在这里。
新版打开旧项目后，标注修改仍自动保存到该项目的 review.jsonl。

A 画框，V 选择；点击框后可拖动移动、拖四角调整。
滚轮缩放；右键或中键拖动画面；F 适合窗口；Esc 取消当前操作。
1 / 2 指定 left / right；X 交换左右；Delete 删除框。
Ctrl+Z 撤销；B / N 上下张；D 下一张待复核。
Space 确认并跳到下一张待复核；Q 确认本张无目标。
E 打开原精细旋转框编辑器。
Ctrl+E 导出训练集；Ctrl+Shift+E 导出全部。

单手新框仍需 1 / 2 明确确认左右；每张最多两个框。
设置窗口中的参数沿用原程序语义；F5 开始检测。

数据集模式下设置置灰：
正在直接编辑已有标签时，检测与抽帧设置不适用。
点击顶部“新建检测项目”，或者设置窗口上方同名按钮，便可切换到新检测项目。
程序会清空界面中的旧输入，并自动分配独立结果目录；已有数据集及已保存标签保留。
新项目设置会直接打开，可添加录像并选择“原图（不去畸变）”。

不去畸变：
1. 输入 / 设置 → 视频 / MCAP 抽帧 → 录像画面处理。
2. 选择“原图（不去畸变）”，设置视频、抽帧间隔和相机路数。
3. 返回标注，点击自动检测（F5）；会先原图抽帧，再在原图上检测。
   也可只点“抽帧并载入”，检查原图后再返回标注按 F5。
原图模式无需相机标定，“保留视野”不参与处理。
“自动”沿用旧逻辑：四目和 MCAP 默认去畸变，普通视频使用原图。
“去畸变”要求可识别的四目录像及标定文件。
模式选择会随最近项目保存，下次启动继续使用。

如果当前已加载去畸变项目，选择原图后按 F5，会从原始录像另抽原图，
结果保存到去掉 _undistorted 后缀的目录，原去畸变项目和人工标注保留。
两个模式的标签坐标不同，不会把去畸变标签直接搬到原图上。
此选项控制视频 / MCAP 抽帧，不能还原已去畸变的普通图片或导出的数据集。

自动检测步骤：读取输入 → 必要时按间隔抽帧 → 按比例/图片间隔抽样 →
SAM3 手套检测与去重选框 → 分配左右类别、标记需复核项 → 保存 review.jsonl。
去畸变模式在原图做 SAM3 分割，再将掩码映射到去畸变图生成框。
F5 会保留已人工确认结果并按规则继续检测；不会自动导出训练集。
